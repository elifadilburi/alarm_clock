# Alarm Clock

A desktop clock app built with Python and Tkinter. It includes alarms, a stopwatch, a countdown timer, and a world map for checking local time.

## Run

Use Python 3 with Tkinter available, then run:

```sh
python3 python_final.py
```

The world map image (`world_map (1).png`) should stay beside the Python files. Tkinter is included with many Python installations; on some Linux systems it must be installed separately.
